Until it is revealed on the TV: do not guess a theme, do not start a themed product, do not write challenge copy.

## Before you build

- Cursor installed and logged in.
- One GitHub repo. Invite the team.
- Everyone clones it and opens that folder in Cursor.
- Share with git. Not Drive. Not LINE.

### Repo

1. One person: `gh repo create` or New repository on GitHub (empty, public or private).
2. Add every teammate as a collaborator.
3. Everyone: `git clone` and File → Open Folder in Cursor. Same remote.
4. Pull before a chunk of work. Commit and push to share.

Do not zip the project. Do not put the working tree on Drive, Dropbox, or LINE.

Solo: skip the invite.
